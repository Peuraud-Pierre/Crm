1 À quoi sert cette page ?

Le Tableau des arrivages centralise le suivi de tous les conteneurs import : depuis leur départ chez le fournisseur jusqu'à leur déchargement en entrepôt. Chaque ligne représente un arrivage, c'est-à-dire un conteneur en cours d'acheminement ou déjà réceptionné.

Sur cette page vous pouvez :

  • Visualiser l'ensemble des arrivages, triés et regroupés par mois.
  • Repérer en un coup d'œil les 5 prochains déchargements et les factures manquantes urgentes.
  • Créer un nouvel arrivage manuellement.
  • Modifier les informations d'un arrivage existant.
  • Exporter tout ou partie du tableau au format Excel.
ℹ️
Les actions disponibles (créer, modifier, exporter) dépendent de vos droits. Si un bouton n'est pas visible, c'est que votre rôle n'inclut pas cette permission.

3 Lire le tableau

Vue d'ensemble du tableau des arrivages, avec l'en-tête (compteur, poids total, boutons Exporter et Nouvel arrivage)

Organisation par mois

Les arrivages sont regroupés par mois et triés du plus récent au plus ancien. Chaque groupe commence par une ligne de titre indiquant le mois, le nombre d'arrivages et le poids total du mois.

La date de référence utilisée pour le classement dans un mois suit cette priorité :

  1. Date de déchargement prévue
  2. Date d'arrivée au port (Le Havre)
  3. Date de départ fournisseur

Pagination

Le tableau affiche 3 mois par page. La navigation s'effectue via les boutons Précédent / Suivant ou en cliquant directement sur un numéro de page.

✅
Astuce : La page s'ouvre automatiquement sur les mois contenant les prochains déchargements. Un point ambre sur un numéro de page indique qu'elle contient au moins un des 5 prochains arrivages.

Colonnes du tableau

ColonneDescription
Statut Badge coloré indiquant l'état de l'arrivage (voir section 4).
Fournisseur Nom du fournisseur et sa localisation si renseignée.

4 Les statuts d'un arrivage

BadgeSignification
Planifié L'arrivage est enregistré mais pas encore expédié.
En transit Le conteneur est en cours d'acheminement.
Reçu La marchandise a été réceptionnée en entrepôt.
Annulé L'arrivage a été annulé. Aucune alerte facture ne s'applique.

Point ambre sur le badge

Un petit point ambre à côté du badge signifie que le statut a été mis à jour automatiquement par le système et attend votre confirmation. Ouvrez l'arrivage pour le confirmer ou le corriger.

5 Les indicateurs visuels

Arrivages imminents (fond ambre)

Les 5 prochains arrivages par date de déchargement prévue sont mis en évidence par :

  • Un fond légèrement ambre sur la ligne.
  • Une barre verticale ambre à gauche de la ligne.
  • La date de déchargement affichée en texte ambre.

Alerte facture manquante (fond rouge)

⚠️
Quand est-ce que l'alerte rouge se déclenche ?
Une ligne passe en rouge lorsque les trois conditions suivantes sont réunies :
  • Aucune date de facture n'est renseignée.
  • Le statut n'est pas "Annulé".
  • Le déchargement est prévu dans moins de 7 jours, ou la date est déjà dépassée.
Dans ce cas : fond rouge, icône ⚠️ dans la colonne Facture, bordure gauche rouge.

Action à effectuer : ouvrez l'arrivage (bouton crayon) et renseignez la date de facture.

6 Créer un arrivage

Cliquez sur + Nouvel arrivage en haut à droite. Un panneau s'ouvre depuis la droite.

Le panneau de création, avec les champs Identification, Transport, Poids & quantité

Choisir le fournisseur Cliquez sur le champ "Rechercher un fournisseur…" et tapez les premières lettres du nom. Sélectionnez le fournisseur dans la liste. Champ obligatoire.
Saisir le N° de conteneur Entrez le numéro BIC du conteneur (ex : CSLU6080095). Le texte est automatiquement mis en majuscules. Champ obligatoire.
Renseigner les informations optionnelles Vous pouvez ajouter : N° interne, date de facture, mode de transport, date de départ, poids et quantité. Ces champs sont tous optionnels à la création.
Valider Cliquez sur Créer l'arrivage. Le formulaire se ferme et la nouvelle ligne apparaît dans le tableau.
ℹ️
Plusieurs champs ne sont disponibles qu'en modification, pas à la création : date de déchargement prévue, date d'arrivée au Havre, statut, et notes. Pour ajouter un commentaire libre sur un arrivage, ouvrez-le après création via le bouton ✏️.

Champs disponibles à la création

ChampObligatoireDescription
Fournisseur✅Fournisseur de la marchandise
N° Conteneur✅Numéro BIC (majuscules automatiques)

Mode de transport—40', 40HC, 20', COMPLET, LCL

7 Modifier un arrivage

Survolez une ligne du tableau et cliquez sur le bouton crayon ✏️ à droite. Sur mobile, le bouton est toujours visible sans survol.

Le panneau de modification s'ouvre avec toutes les informations déjà remplies. Vous pouvez modifier n'importe quel champ.

Champs supplémentaires disponibles en modification

ChampDescription
Date & heure de déchargement Date et heure précises du déchargement prévu. S'affiche au format local (ex : "Lundi · 23/06/26 · 08:30"). Un indicateur J-X est calculé automatiquement.
Statut Modifier manuellement le statut de l'arrivage.
Arrivée Le Havre Date d'arrivée au port du Havre.
Notes Commentaire libre sur l'arrivage.

Alertes dans le formulaire d'édition

⚠️
Facture manquante — Une bannière rouge s'affiche si le déchargement est prévu dans moins de 7 jours (ou passé) et qu'aucune date de facture n'est renseignée. Le champ "Date facture" est mis en rouge. Saisissez la date pour faire disparaître l'alerte.

La bannière rouge "Facture manquante" dans le panneau d'édition, avec le nombre de jours de retard

⚠️
Statut mis à jour automatiquement — Une bannière ambre s'affiche si le système a modifié le statut automatiquement. Vous pouvez cliquer OK pour confirmer, ou choisir un autre statut dans la liste. Toute sauvegarde confirme automatiquement le statut.

Indicateur J-X

Quand une date de déchargement est saisie, un indicateur apparaît sous le champ :

  • J-3 : déchargement dans 3 jours
  • J : déchargement aujourd'hui
  • J+2 : déchargement passé depuis 2 jours

Cliquez sur Enregistrer pour sauvegarder les modifications.

8 Exporter en Excel et imprimer

Deux modes d'export et une impression papier sont disponibles depuis les boutons en haut à droite du tableau.

Export complet (bouton "Exporter")

Cliquer sur "Exporter" Le fichier Excel est généré et téléchargé immédiatement. Il contient tous les arrivages, sans filtre de date.

Export par période (icône calendrier)

Le sélecteur de plage de dates, ouvert depuis l'icône calendrier

Cliquer sur l'icône calendrier 📅 Un sélecteur de plage de dates s'ouvre.
Sélectionner la plage Cliquez sur la date de début, puis sur la date de fin. La plage sélectionnée est affichée en bas du calendrier.
Cliquer sur "Télécharger" Seuls les arrivages dont la date de référence (déchargement ou Le Havre ou départ) tombe dans la plage sont inclus.

Imprimer le tableau (bouton "Imprimer")

Le bouton Imprimer, à gauche des boutons d'export, ouvre une fenêtre qui vous laisse choisir ce qui part à l'imprimante et vérifier le résultat avant de lancer l'impression.

Choisir le format Détaillé reprend le tableau complet, comme le fichier Excel. Simple resserre l'essentiel sur huit colonnes, pour tenir sur le moins de pages possible. Les deux s'impriment en paysage.
Choisir la période Le mois en cours est proposé par défaut. Le nombre d'arrivages concernés s'affiche à côté du sélecteur.
Vérifier l'aperçu, puis cliquer sur "Imprimer" L'aperçu affiché est exactement ce qui sera imprimé. La fenêtre d'impression de votre navigateur s'ouvre ensuite.
ℹ️
Le format simple reprend, mois par mois, les colonnes Fournisseur, Date facture, Départ, Le Havre, N° Conteneur, Déchargement (jour, date et heure), Poids et Quantité — tout sauf le statut. Comme dans le fichier Excel, la colonne Date facture est en rouge et la colonne Déchargement en bleu. Les arrivages dont la facture manque à moins de 7 jours du déchargement portent un ⚠ dans la colonne Facture, expliqué en bas de page.
🖨️
Si les couleurs n'apparaissent pas sur le papier, activez l'option « Graphiques d'arrière-plan » (ou « Background graphics ») dans la fenêtre d'impression de votre navigateur. Le choix paysage/portrait y est volontairement grisé : les deux formats sont conçus pour le paysage.

9 Questions fréquentes

Je ne vois pas le bouton "Nouvel arrivage"

Ce bouton est masqué si vous ne disposez pas du droit de création. Contactez votre administrateur pour obtenir cette permission.

Ma ligne est en rouge mais la facture est bien reçue

Ouvrez l'arrivage (bouton crayon) et renseignez la date de facture dans la section "Facturation". L'alerte disparaît dès qu'une date est enregistrée.

Le statut a changé tout seul

Le système peut mettre à jour certains statuts automatiquement. Un point ambre sur le badge vous indique que ce statut doit être confirmé. Ouvrez l'arrivage et cliquez sur "Enregistrer" pour confirmer.

Comment trouver un arrivage d'un mois passé ?

Naviguez vers les pages précédentes du tableau à l'aide des boutons Précédent / Suivant ou en cliquant sur les numéros de page.

L'export ne contient pas toutes les colonnes

Les colonnes visibles dans l'export dépendent de vos droits d'accès. Certaines colonnes (ex : Notes, Lieu) peuvent être masquées selon votre rôle. Contactez l'administrateur si vous avez besoin d'accéder à des données manquantes.

Je ne vois pas la date de déchargement dans le tableau mais elle est renseignée

La date de déchargement est affichée uniquement si elle a été saisie dans le formulaire d'édition. Vérifiez le champ "Date & heure prévues" dans le panneau de modification de l'arrivage concerné.

10 S'abonner à la newsletter des arrivages

La newsletter des arrivages permet de recevoir par e-mail un état à jour du tableau, sans avoir besoin de se connecter à la Console. L'envoi se déclenche automatiquement dès qu'un arrivage est ajouté, modifié ou supprimé (avec un court délai pour regrouper les changements rapprochés).

S'abonner

L'abonnement se fait depuis votre profil (et non depuis une page d'administration) : une carte "Newsletter Arrivages" y apparaît si vous disposez du droit correspondant.

  1. Ouvrez votre profil et repérez la carte "Newsletter Arrivages".
  2. Cochez les colonnes que vous souhaitez recevoir dans le fichier Excel joint à chaque e-mail.
  3. Renseignez le code d'invitation (format ARV-XXXXXXXX) qu'un administrateur doit avoir créé au préalable pour vous — sans ce code, l'abonnement n'est pas possible.
  4. Cliquez sur "S'abonner".

Si vous n'avez pas de code d'invitation, demandez-en un à votre administrateur.

Modifier ses colonnes ou se désabonner

Une fois abonné, revenez sur la même carte dans votre profil : cochez/décochez des colonnes puis cliquez sur "Mettre à jour", ou cliquez sur "Se désabonner" pour arrêter les envois (le code d'invitation n'est pas redemandé pour ces actions).
